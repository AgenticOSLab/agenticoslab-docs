# Agentic OS

Agentic OS - это не продукт, а архитектурный паттерн

Он определяет высокоуровневую структуру всей системы на базе искусственного интеллекта, распределение глобальных обязанностей и принципы взаимодействия крупных модулей, а не локальную композицию классов.

## Что проектируем?

Систему организации использования ИИ в целом (Ядро, Память, Диспетчеризация, Агенты).

> **Аналогия** - Чертеж целого здания

Архитектура Agentic OS типично делится на независимые слои:

## Архитектурный слои

1. _Слой приложений (Application Layer):_ Специализированные AI-агенты (агент-программист, агент-аналитик).
2. _Ядро (LLM Kernel / OS Layer):_ Системные службы — диспетчер контекста (Context Manager), планировщик задач (Scheduler), менеджер памяти (Memory Manager) и подсистема безопасности (Guardrails).
3. _Слой ресурсов (Hardware/Infra Layer):_ Модели (LLM), базы данных векторного поиска (RAG) и инструменты.
